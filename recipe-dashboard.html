🔑 Connect Google Drive

One-time setup so your phone can save & load recipes from Google Drive automatically.

Setup steps (5 min):
1. Go to console.cloud.google.com
2. Create a project (or pick an existing one)
3. APIs & Services → Enable APIs → enable Google Drive API
4. APIs & Services → Credentials → Create Credentials → OAuth client ID
5. Application type: Web application
6. Authorized JavaScript origins: add your Netlify URL (e.g. https://your-app.netlify.app)
7. Copy the Client ID and paste it below

Find this next to your Client ID in Google Cloud Console → Clients

📱 Email Sync Link to Phone

Enter your Netlify app URL so the link opens your Recipe Box on your phone.

Your sync link is ready! Copy it and email/text it to yourself, then tap it on your phone.

On your phone: tap the link → Safari opens your Recipe Box → recipes load automatically.
